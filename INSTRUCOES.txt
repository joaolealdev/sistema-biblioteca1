🚀 INICIAR RÁPIDO (Assume MongoDB já instalado e rodando):

1. Instalar dependências:
   npm install

2. Popular banco (opcional):
   node seed.js

3. Iniciar servidor:
   npm start

4. Acessar no navegador:
   http://localhost:3000

🗄️ BANCO DE DADOS MongoDB:

Nome do banco: biblioteca
Coleções: livros, emprestimos

Estrutura de Livros:
{
  _id: ObjectId,
  titulo: String,
  autor: String,
  isbn: String,
  quantidade: Number,
  disponiveis: Number,
  criadoEm: Date
}

Estrutura de Empréstimos:
{
  _id: ObjectId,
  livroId: ObjectId,
  tituloLivro: String,
  nomeUsuario: String,
  emailUsuario: String,
  dataEmprestimo: Date,
  devolucaoPrevista: Date,
  status: "ativo" | "devolvido"
}

================================================================================

🔌 API REST:

GET    /livros              - Listar todos os livros
GET    /livros/:id          - Buscar livro por ID
POST   /livros              - Criar novo livro
PUT    /livros/:id          - Atualizar livro
DELETE /livros/:id          - Remover livro

GET    /emprestimos         - Listar empréstimos
GET    /emprestimos/:id     - Buscar empréstimo
POST   /emprestimos         - Criar empréstimo
PATCH  /emprestimos/:id/devolver - Devolver livro
